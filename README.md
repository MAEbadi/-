# داشبورد فروش محصولات دارویی (اکسل)

## نگاه کلی
تحلیل فروش و محصولات و انبار یک شرکت داروسازی با استفاده از یک داشبورد تعاملی در مایکروسافت اکسل

## قابلیت‌ها
-پیووت تیبل‌ها
- جداول پیووت
- اسلایسرها
- کارت‌های KPI
- داشبورد متحرک

## ابزارها
- مایکروسافت اکسل
- پیووت تیبل
- چارت‌های اکسل
